# 🚀 HestiaCP Auto Deploy

**Полная автоматическая установка HestiaCP с настройкой доменов, SSL и файлов**

---

## 📋 **Описание**

Этот скрипт автоматически:
- ✅ Устанавливает HestiaCP на сервер
- ✅ Добавляет неограниченное количество доменов
- ✅ Загружает ваши файлы (`index.php`, `.htaccess` и другие)
- ✅ Устанавливает SSL сертификаты (Let's Encrypt)
- ✅ Включает автоматический HTTPS редирект
- ✅ Перезагружает сервер в конце установки

---
